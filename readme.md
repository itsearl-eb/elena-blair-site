# Elena Blair — Site (Eleventy)

Static site, generated by [Eleventy](https://www.11ty.dev/). One data file is the
source of truth for every project page, the archive grid, prev/next, and OG tags.

## Layout
```
.eleventy.js              build config + the `cld` Cloudinary filter
netlify.toml              Netlify build command + publish dir
package.json
src/
  _data/projects.js       ← THE ONE FILE you edit to add/remove/reorder a project
  _includes/
    base.njk              shared shell: head, fonts, css, nav, footer
    frame.njk             img macro (srcset/sizes/ratio by role + orientation)
  projects.njk            generates /projects/{slug}/ for every manifest entry
  the-archive.njk         generates /the-archive/ grid from the manifest
  css/                    ← put eb.css + project.css here
  static/                 ← optional: og-image.png, favicon, robots.txt (copied to root)
```

## Local dev
```
npm install
npm run dev      # serves at http://localhost:8080, live reload
npm run build    # outputs to _site/
```

## Deploy (Netlify)
`netlify.toml` runs `npx @11ty/eleventy` and publishes `_site/`. This is still **one
deploy per merge to main** — the Eleventy build runs inside that deploy, it does not
add credit spend. Same workflow as before: batch commits on `dev`, merge to `main`
at a milestone.

## Add a project
1. Upload images to Cloudinary, note each PLAIN url (the `/upload/v.../` one).
2. Append an object to the array in `src/_data/projects.js`:
   - `slug`, `title`, `shootType`, `date` (ISO `YYYY-MM-DD`)
   - `metaDescription`, `standfirst`
   - `opening`: `mode` (A/B), `tone` (light/dark), `hero` frame
   - `sequence`: rows of `{ type:"full", frame }` or `{ type:"pair", frames:[a,b] }`
   - `credits`, `ogImageBase`
3. That's it. Newest `date` sorts first; prev/next (looped) and the archive card
   generate automatically. Remove a project = delete its object — no dead links.

Per frame you store only the plain url + `orientation` + `alt`. The `cld` filter
builds every srcset width — never hand-write srcset again. Default ratios are
portrait 1728×2304 / landscape 2304×1728; override with `w`/`h` for odd crops.

## URL shape
Pages are now `/projects/{slug}/` (pretty) instead of `/projects/{slug}.html`.
Matches the existing `og:url` pattern. Update any old hardcoded links.
